OneTool — Libraries Reference

OneTool ships four internal libraries that provide the building blocks for all tools. Each is implemented entirely from scratch in C (except the TUI library which wraps ncurses). This document covers every function, structure, enum, and implementation detail.

1. TUI Library — libs/TUI/

Files: tui.h (83 lines), tui.c (460 lines)

The TUI library is an ncurses-based abstraction layer providing palette management, styled drawing primitives, input handling, and screen framing. It is used by the main TUI (tui.c), the task manager (taskmng), and the user control tool (userc).

1.3 Palette Structure

The tui_palette_t struct defines 7 color slots that control the entire visual appearance:

typedef struct {
    int background;  // Terminal background color
    int panel;       // Panel/status bar background color
    int accent;      // Highlight color for titles, selected tool names
    int text;        // Primary text color
    int muted;       // Secondary/hint text color
    int success;     // Success indicator color
    int error;       // Error message color
} tui_palette_t;

Implementation detail: When a palette is applied via apply_palette(), the selection style uses the background color as its foreground with the accent color as its background — effectively inverting the accent. init_pair() is called for each of the 7 pair IDs, creating color pairs 1-7 in ncurses.

1.5 API Functions — Complete Reference

int tui_init(void)

Initializes the ncurses terminal. Implementation steps:

  • Calls newterm(NULL, stdout, stdin) to initialize terminal
  • Enables cbreak() for character-by-character input
  • Disables echo() so typed keys don't show
  • Enables keypad(stdscr, TRUE) for arrow/function keys
  • Hides cursor via curs_set(0)
  • Sets escape delay to 25ms via set_escdelay(25) (if ncurses)
  • If colors are supported: calls start_color(), use_default_colors(), and apply_palette()
  • Returns 0 on success, 1 on failure

void tui_shutdown(void)

Restores terminal to its original state via endwin(). Safe to call multiple times — uses a static tui_ready flag.

void tui_begin_frame(void)

Calls clear() to erase the screen at the start of each frame.

void tui_end_frame(void)

Calls refresh() to flush all pending drawing operations to the terminal.

void tui_clear(int style)

Fills the entire screen with the background character space (' ') using the given style's color pair. Sets the background character via bkgdset() then clears.

void tui_get_size(int *width, int *height)

Uses getmaxyx(stdscr, max_y, max_x) to retrieve terminal dimensions. Sets width and height to 0 if TUI is not initialized.

int tui_poll_event(tui_event_t *event, int timeout_ms)

Polls for keyboard input:

  • Sets timeout(timeout_ms) for non-blocking input
  • Reads a key with getch()
  • If ERR (timeout), returns 0
  • Otherwise translates the raw keycode via translate_key(), sets event->kind and event->key, returns 1

Key translation: The translate_key() function maps ncurses KEY_* constants to OneTool's TUI_KEY_* enum. It handles: KEY_UP, KEY_DOWN, KEY_LEFT, KEY_RIGHT, KEY_HOME, KEY_END, KEY_PPAGE, KEY_NPAGE, KEY_DC (delete), KEY_BACKSPACE (and 127 and 8), \n \r KEY_ENTER, \t, ESC (27), KEY_RESIZE.

void tui_set_palette(const tui_palette_t *palette)

Copies the palette struct into the internal static tui_palette, then calls apply_palette() if colors are available and TUI is initialized. All color pairs are re-initialized with the new colors.

void tui_draw_text(int x, int y, int style, const char *text)

Draws text at screen position (x, y) using the given style:

  • Bounds-checks y against terminal height
  • Handles negative x by advancing the text pointer and reducing x to 0
  • Clips width to max_x - x
  • Uses mvaddnstr(y, x, text, width) with the style's attribute

void tui_draw_textf(int x, int y, int style, const char *fmt, ...)

Formats text with vsnprintf() (1024-byte buffer) then calls tui_draw_text().

void tui_fill_rect(int x, int y, int width, int height, int style, char fill)

Fills a rectangular area with a repeating character:

  • Clips rectangle to screen bounds via clip_rect_to_screen()
  • Uses nested loops with mvaddch() for each cell

void tui_draw_box(int x, int y, int width, int height, int style, const char *title)

Draws a bordered box:

  • Corners: ACS_ULCORNER, ACS_URCORNER, ACS_LLCORNER, ACS_LRCORNER
  • Edges: ACS_HLINE (horizontal), ACS_VLINE (vertical)
  • Title: If provided and box is wide enough, draws ACS_RTEE + title + ACS_LTEE on the top border, 2 characters from left

void tui_draw_hline(int x, int y, int width, int style, char ch)

Draws a horizontal line of repeated characters using mvaddch() in a loop.

void tui_draw_vline(int x, int y, int height, int style, char ch)

Draws a vertical line of repeated characters using mvaddch() in a vertical loop.

void tui_draw_status_line(int style, const char *text)

Draws a status bar at the bottom row of the terminal:

  • Fills the entire last row with spaces in the given style
  • Draws the text clipped to terminal width minus 1 using tui_clip_text()

int tui_key_is_printable(int key)

Returns 1 if key is in range 32-126 (printable ASCII), 0 otherwise.

const char *tui_clip_text(const char *src, char *dst, int dst_size, int width)

Clips text to fit a given width with ellipsis:

  • If src is shorter than width, copies directly
  • If width is 1 or 2, returns ".", ".."
  • Otherwise copies first width - 3 characters then appends "..."
  • Returns dst pointer, or "" if src is NULL

2. ELF Library — libs/elf/

Files: elf.h (52 lines), elf.c (172 lines)

A lightweight ELF64 parser that reads from memory buffers. Used by size, nm, and mlink tools. Supports little-endian ELF64 only.

2.1 Core Structures

ot_elf_section_t

Represents a single ELF section header entry after parsing:

typedef struct {
    char *name;            // Section name string (allocated, from .shstrtab)
    uint32_t name_offset;  // Raw index into .shstrtab
    uint32_t type;         // Section type: SHT_PROGBITS(1), SHT_NOBITS(8),
                          //   SHT_SYMTAB(2), SHT_STRTAB(3), SHT_RELA(4),
                          //   SHT_HASH(5), SHT_DYNAMIC(6), etc.
    uint64_t flags;        // SHF_WRITE(0x1), SHF_ALLOC(0x2), SHF_EXECINSTR(0x4),
                          //   SHF_MERGE(0x10), SHF_STRINGS(0x20), SHF_TLS(0x400)
    uint64_t addr;         // Virtual address at runtime (after loading)
    uint64_t offset;       // File offset
    uint64_t size;         // Section size in bytes
    uint32_t link;         // Link to another section (e.g. symtab→strtab index)
    uint32_t info;         // Extra info (e.g. symtab's last local symbol + 1)
    uint64_t addralign;    // Alignment requirement (power of 2)
    uint64_t entsize;      // Entry size for tables (e.g. 24 for symtab, 24 for rela)
} ot_elf_section_t;

ot_elf_file_t

Represents a fully parsed ELF file:

typedef struct {
    const char *name;           // File name (borrowed pointer, not owned)
    const unsigned char *data;  // Raw file data pointer
    size_t size;                // File size
    uint16_t type;              // ET_NONE(0), ET_REL(1), ET_EXEC(2), ET_DYN(3)
    uint16_t machine;           // EM_X86_64(62), EM_386(3), etc.
    uint64_t entry;             // Entry point virtual address
    uint16_t shstrndx;          // Section header string table index
    ot_elf_section_t *sections; // Parsed section array (allocated)
    size_t section_count;       // Number of sections
} ot_elf_file_t;

2.2 API Functions — Complete Reference

void ot_elf_init(ot_elf_file_t *elf)

Zero-initializes an elf file struct via memset(elf, 0, sizeof(*elf)). Must be called before ot_elf_parse().

void ot_elf_free(ot_elf_file_t *elf)

Frees all allocated resources:

  • Iterates through all sections and calls free() on each section's name
  • Frees the sections array
  • Zeroes the entire struct

int ot_elf_parse(ot_elf_file_t *elf, const char *name, const unsigned char *data, size_t size, char *err, size_t err_size)

Parses an ELF file from memory. Returns 0 on success, 1 on error.

Validation steps:

  1. Checks that data is at least EI_NIDENT (16) bytes and starts with ELF magic (0x7f 'E' 'L' 'F')
  2. Checks data is at least 64 bytes (minimum ELF64 header size)
  3. Checks EI_CLASS == ELFCLASS64 (2) — 32-bit ELF rejected
  4. Checks EI_DATA == ELFDATA2LSB (1) — big-endian rejected
  5. Checks EI_VERSION == EV_CURRENT (1)

Parsing steps:

  1. Reads section header table offset from offset 40 (8 bytes)
  2. Reads section header entry size from offset 58 (2 bytes) — must be 64
  3. Reads section count from offset 60 (2 bytes)
  4. Reads shstrndx from offset 62 (2 bytes)
  5. Validates section table fits in file via ot_elf_range_ok()
  6. Validates shstrndx is not SHN_UNDEF (0) and is within section count
  7. Allocates and parses all section headers (each 64 bytes)
  8. Reads the section string table, then resolves each section's name
  9. Sets metadata: type, machine, entry point, shstrndx

int ot_elf_range_ok(size_t file_size, uint64_t off, uint64_t size)

Validates that off + size fits within file_size:

return off <= file_size && size <= file_size - off;

This is the standard overflow-safe range check used throughout the ELF parser.

char *ot_elf_strdup_from_strtab(const unsigned char *base, size_t size, uint32_t off)

Extracts a null-terminated string from a string table at a given offset:

  • If offset is out of bounds, returns ""
  • Scans from offset until null byte or end of table
  • Allocates and copies the string via ot_xmalloc() + memcpy
  • If no null byte found before end, returns ""

2.3 Byte Accessors

All multi-byte values in ELF files are little-endian. These accessors perform manual byte-wise reading/writing to avoid endianness dependencies on the host system:

FunctionImplementation
ot_elf_get16(p)p[0] | (p[1] << 8)
ot_elf_get32(p)p[0] | (p[1]<<8) | (p[2]<<16) | (p[3]<<24)
ot_elf_get64(p)get32(p) | ((uint64_t)get32(p+4) << 32)
ot_elf_put16(p, v)Write two bytes LSB first
ot_elf_put32(p, v)Write four bytes LSB first
ot_elf_put64(p, v)Write 8 bytes via put32(p, low) + put32(p+4, high)

3. Network Library — libs/net/

Files: net.h (59 lines), url.c (96 lines), transport.c, http.c (347 lines), robots.c

Three-layer networking stack: URL parsing, TCP/TLS transport, and HTTP client. The HTTP response parser was partially AI-generated.

3.1 URL Parser — url.c

net_url_t

typedef struct {
    char *host;    // Hostname (e.g. "example.com")
    char *port;    // Port string (e.g. "80" or "443")
    char *path;    // Path + query string (e.g. "/index.html?q=1")
    int use_tls;   // 1 for https://, 0 for http://
} net_url_t;

int net_parse_http_url(const char *url, net_url_t *out)

Parses an HTTP/HTTPS URL. Returns 0 on success, 1 on error.

Parsing algorithm:

  1. Checks for "http://" prefix (7 chars) → no TLS
  2. Checks for "https://" prefix (8 chars) → TLS
  3. If no scheme prefix, defaults to HTTP
  4. Scans forward from host start to find '/' (path separator) or end of string
  5. Within host part, scans for ':' to detect explicit port
  6. If port found: splits host and port segments, allocates both
  7. If no port: allocates host, sets default port (443 for TLS, 80 otherwise)
  8. Sets path: defaults to "/" if empty, copies path_start otherwise
  9. All strings allocated with malloc()

void net_free_url(net_url_t *url)

Frees all allocated string fields (host, port, path) and zeroes the struct.

3.2 Transport Layer — transport.c

net_conn_t

typedef struct {
    int fd;             // TCP socket file descriptor
    void *ssl_ctx;      // SSL context (opaque handle, NULL if no TLS)
    void *ssl;          // SSL connection object (opaque handle, NULL if no TLS)
    int use_tls;        // 1 if TLS is active
} net_conn_t;

int net_conn_open(net_conn_t *conn, const char *host, const char *port, int timeout_sec, int use_tls, const char *tls_server_name, int noisy)

Opens a TCP connection to the specified host:port with optional TLS upgrade:

  • Resolves hostname via getaddrinfo()
  • Creates a socket with socket(AF_INET, SOCK_STREAM, 0)
  • Sets socket non-blocking for connect with timeout
  • Uses poll() to wait for connection with configurable timeout
  • If TLS: wraps the fd with OpenSSL (or equivalent), performs handshake
  • Returns 0 on success, non-zero on failure

void net_conn_close(net_conn_t *conn)

Closes the connection:

  • If TLS active: performs SSL shutdown via SSL_shutdown(), frees SSL and SSL_CTX
  • Closes the socket fd via close()

ssize_t net_conn_read(net_conn_t *conn, void *buf, size_t len)

Reads data from the connection. If TLS active, uses SSL_read(), otherwise read().

ssize_t net_conn_write(net_conn_t *conn, const void *buf, size_t len)

Writes data to the connection. If TLS active, uses SSL_write(), otherwise write().

3.3 HTTP Layer — http.c

net_http_response_t

typedef struct {
    int status_code;            // HTTP status code (200, 404, 500...)
    int chunked;                // 1 if Transfer-Encoding: chunked
    long long content_length;   // Content-Length header value (-1 if absent)
    long long body_bytes;       // Total body bytes actually written
} net_http_response_t;

Internal Stream Type

typedef struct {
    net_conn_t *conn;           // Network connection
    const unsigned char *prefill;   // Already-read data buffer
    size_t prefill_len;             // Amount of prefill data available
    size_t prefill_pos;             // Current read position in prefill
} stream_t;

The stream_t type implements a buffered read layer over the connection. Initial HTTP response data that was read while searching for the header terminator is stored in prefill so it can be consumed before reading more data from the socket.

int net_http_send_request(net_conn_t *conn, const char *method, const char *path, const char *host, const char *headers[], int header_count, const char *body, const char *user_agent)

Builds and sends an HTTP/1.1 request. Returns 0 on success, 1 on failure.

Request construction:

METHOD path HTTP/1.1\r\n
Host: host\r\n
User-Agent: user_agent\r\n
Accept: */*\r\n
Connection: close\r\n
[custom headers...]\r\n
Content-Length: body_len\r\n
\r\n
body

The request is formatted into a 16KB static buffer using snprintf(). Custom headers are appended verbatim. Content-Length is included only if a body is provided. The request is sent via send_all() which handles partial writes and EINTR.

int net_http_read_response(net_conn_t *conn, FILE *out, int verbose, net_http_response_t *resp)

Reads and parses an HTTP response body. Returns 0 on success, 1 on failure.

Implementation details:

  1. Header accumulation: Reads data from socket in 8KB chunks into a dynamically growing buffer (initial 16KB, doubles as needed). Searches for "\r\n\r\n" (end of headers).
  2. Header parsing: Duplicates the header portion, tokenizes by "\r\n" with strtok(). Extracts status code from the first line. Scans for Content-Length and Transfer-Encoding: chunked headers.
  3. Body reading — chunked: Calls read_chunked() which loops: reads a hex chunk size line, reads that many bytes, writes them to output, reads trailing CRLF. Continues until a zero-length chunk, then consumes trailing headers.
  4. Body reading — content-length: First writes any prefilled data, then reads exactly content_length - prefilled more bytes in a loop.
  5. Body reading — connection close: (no content-length, no chunked) Reads until connection returns 0 bytes.
  6. Always flushes output via fflush(out).

Helper: static int send_all(net_conn_t *conn, const void *buf, size_t len)

Writes all len bytes to the connection, handling partial writes and EINTR. Returns 0 on success.

Helper: static int stream_read_exact(stream_t *s, unsigned char *dst, size_t len)

Reads exactly len bytes from the stream. Uses prefill buffer first, then reads from connection. Returns 0 on success.

Helper: static int stream_read_line(stream_t *s, char *line, size_t cap)

Reads one byte at a time until '\n' is found, then null-terminates. Returns 0 on success.

3.4 Robots.txt Checker — robots.c

int net_robots_is_allowed(const char *host, const char *port, int use_tls, int timeout_sec, const char *path, const char *user_agent, int verbose, int *allowed)

Fetches and parses /robots.txt from the target server, then checks if the given path is allowed for the given user agent.

Algorithm:

  1. Opens an HTTP connection to the server
  2. Sends a GET request for /robots.txt
  3. Reads the response body (non-chunked, connection-close mode)
  4. Parses line by line: User-agent:, Disallow:, Allow: directives
  5. Finds the matching user-agent section (first exact match, then wildcard *)
  6. Checks if the requested path matches any Disallow rule (prefix match)
  7. Sets *allowed to 0 (disallowed) or 1 (allowed)
  8. Returns 0 on success (fetch and parse worked), non-zero on fetch failure

4. Memory Library — libs/memory/

Files: memory.h (13 lines), memory.c (67 lines)

Checked allocation wrappers that abort on failure. Every heap allocation in OneTool goes through these (ot_xmalloc, ot_xcalloc, ot_xrealloc, ot_xreallocarray, ot_xstrdup, ot_xstrndup) to guarantee OOM safety without cluttering code with NULL checks.

4.1 Core Concepts

  • Non-zero size: All functions convert size 0 to 1 (nonzero_size()) to avoid implementation-defined malloc(0) behavior
  • Overflow protection: checked_mul() prevents integer overflow in multiplication (used by calloc and reallocarray)
  • Failure behavior: Prints "onetool: out of memory" to stderr and calls exit(2)

4.2 API Functions

void *ot_xmalloc(size_t size)

Wraps malloc(). If size is 0, allocates 1 byte. Aborts if NULL returned and size was non-zero.

void *ot_xcalloc(size_t count, size_t size)

Wraps calloc(). First computes total = count * size with overflow check (checked_mul()). Then allocates with calloc(1, total), converting 0 to 1. Aborts if NULL.

void *ot_xrealloc(void *ptr, size_t size)

Wraps realloc(). Converts size 0 to 1. Aborts if NULL returned.

void *ot_xreallocarray(void *ptr, size_t count, size_t size)

Computes total = count * size with overflow check, then calls ot_xrealloc(ptr, total).

char *ot_xstrdup(const char *s)

Wraps strdup(): computes length via strlen(), allocates len + 1 via ot_xmalloc(), copies with memcpy().

char *ot_xstrndup(const char *s, size_t len)

Wraps strndup(): allocates len + 1 via ot_xmalloc(), copies len bytes, null-terminates.

4.3 Private Helpers

static void oom(void) {
    fprintf(stderr, "onetool: out of memory\n");
    exit(2);
}

static size_t nonzero_size(size_t size) {
    return size == 0 ? 1 : size;
}

static size_t checked_mul(size_t count, size_t size) {
    if (count != 0 && size > SIZE_MAX / count) {
        oom();  // Overflow detected
    }
    return count * size;
}
