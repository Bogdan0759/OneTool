OneTool — MOFL Language Subsystem

The MOFL subsystem (licensed under BSD 2-Clause) contains two language implementations: YAP and Brainfuck. These are registered via the extra tools manifest and built as part of OneTool.

YAP Language

Source: mofl/languages/yap/yap.c (1132 lines)

Entry: Registered as extra tool yap

YAP (Yet Another Programming language) is a scripting language interpreter bundled with OneTool. It supports variables, math operations, control flow, external library calls, and subroutines.

Features

  • Variables (declared before use)
  • Integer and string types
  • Arithmetic: ADD, SUB, MUL, DIV
  • Conditional blocks: IF/ENDIF
  • Comparison operators: B (bigger), S (smaller), E (equal)
  • Subroutine calls via GOTO/RETURN
  • External dynamic library calling (Linux .so, Windows .dll)
  • Print output: raw values, strings, numbers
  • User input: READINT
  • System variables: OPRES (math results), RETVAL (return values)

Language Syntax

Comments

; this is a comment
; everything after semicolon is ignored

Variables

DECLARE VAR name
SET name "John"
PRINT name

Print Options

PRINT NFORMAT hello    ; print raw value (no variable lookup)
PRINT "hello"          ; print string literal
PRINT 123              ; print number

User Input

READINT number
PRINT number           ; prints the read number
; READINT stores the value into the variable
; and also updates OPRES with the same integer

Math Operations

ADD 2, 3
PRINT OPRES            ; prints 5

SUB 10 4
SET result OPRES       ; result = 6

MUL result 2
PRINT OPRES            ; prints 12

DIV 20 5
PRINT OPRES            ; prints 4

All math results are stored in the system variable OPRES. Return values from subroutines are stored in RETVAL.

If Blocks

IF name E "John"
  PRINT "user is John"
ENDIF

IF 10 B 3
  PRINT "ten is bigger"
ENDIF

IF NFORMAT name E "name"
  PRINT "compare raw token without variable lookup"
ENDIF

Supported comparison operators:

OperatorMeaning
BBigger (greater than)
SSmaller (less than)
EEqual

Operators can also be written at the end:

IF 10 3 B
PRINT "same meaning as IF 10 B 3"
ENDIF

Subroutines (GOTO/RETURN)

; Line numbers are addresses (starting from 1)
; Each line is an address you can jump to
; After GOTO finishes (see RETURN), execution continues
; on the line after GOTO

1:  PRINT "start"
2:  GOTO 5
3:  PRINT "skipped"         ; this is skipped
4:  RETURN "done"           ; return to GOTO LINE + 1
5:  PRINT "subroutine"
6:  RETURN "back"           ; jump back to line 3
7:  PRINT RETVAL            ; prints "back"

External Library Calls

; Linux
CALL "/full/path/libexample.so" add_numbers INT2 2 3
PRINT OPRES

; Windows
CALL "C:\full\path\example.dll" "hello" STR1 "world"
PRINT RETVAL

Supported call signatures:

SignatureC Function
INT0int func(void)
INT1int func(int)
INT2int func(int, int)
INTSTR1int func(const char*)
STR0const char* func(void)
STR1const char* func(const char*)

Interpreter Internals

The interpreter has a lexer (struct lexer) that tokenizes source lines, a line parser, and an execution engine. Key internal structures:

  • Lexer: Splits input text into token lists
  • Parsed lines: Each line struct parsed_line holds up to MAXTOKENS (28) tokens
  • Execution: Interprets line by line with support for jump table (GOTO targets)
  • System variables: OPRES stores math/results, RETVAL stores subroutine return values

Brainfuck Language

Source: mofl/languages/brainfuck/

Brainfuck is implemented in three ways within the project:

Compiler — compiler/compbf.c

An optimizing Brainfuck compiler that translates Brainfuck source code into native machine code (or intermediate representation).

Interpreters

FileLanguageDescription
interpreter/asbf.sx86-64 AssemblyA hand-optimized Brainfuck interpreter in assembly language
interpreter/pybf.pyPythonA Python-based Brainfuck interpreter for reference and testing

Brainfuck Example

The examples/mandelbrot.bf file contains a Mandelbrot set renderer written in Brainfuck — a classic demonstration of the language's computational completeness.

Brainfuck Language Reference

Brainfuck operates on an array of memory cells (typically 30,000 bytes), a data pointer, and uses 8 commands:

CommandMeaning
>Increment the data pointer (move right)
<Decrement the data pointer (move left)
+Increment the byte at the data pointer
-Decrement the byte at the data pointer
.Output the byte at the data pointer
,Input a byte and store it at the data pointer
[Jump forward to matching ] if byte at pointer is zero
]Jump back to matching [ if byte at pointer is non-zero
